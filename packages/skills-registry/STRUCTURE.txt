HOW TO RUN
==========

1. Install dependencies:
   pip install -r requirements.txt

2. Configure environment (optional):
   export LOGGING_DB_HOST=localhost
   export LOGGING_DB_NAME=skills_logs
   export LOGGING_DB_USER=postgres
   export LOGGING_DB_PASSWORD=postgres

3. Start server:
   python -m oai_skills_registry.main

4. Server runs at:
   http://localhost:8002

5. API docs available at:
   http://localhost:8002/docs (Swagger UI)
   http://localhost:8002/redoc (ReDoc)
